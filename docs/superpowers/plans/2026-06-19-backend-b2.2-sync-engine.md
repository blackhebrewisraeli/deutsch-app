# B2.2 — Sync engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `src/lib/sync.js` + a pure merge core that pushes local progress (SRS, daily stats, settings) to the three live Supabase tables when a session exists, pulls on sign-in/resume, and merges a guest's local progress into an account on first sign-in — all behind `VITE_SYNC_ENABLED`, a complete no-op when off/signed-out/offline.

**Architecture:** A pure, fully-unit-tested merge core (`src/lib/sync/merge.js`) decides record-level outcomes (SRS last-write-wins by `lastReviewed`; daily stats **additive via delta-sync**; settings LWW by `settingsUpdatedAt`). Per-store adapters (`src/lib/sync/adapters.js`) map the local blob ↔ table rows. The orchestrator (`src/lib/sync.js`) wires the core to `src/lib/auth.js`'s session + Supabase client with a debounced push and pull-on-resume. `localStorage` stays the offline source of truth; no existing storage key is renamed (Phase-4 constraint).

**Tech Stack:** React 18, Vite 5 (`import.meta.env.VITE_SYNC_ENABLED`), `@supabase/supabase-js` (via `src/lib/auth.js` only), Vitest 2 + jsdom + RTL (`globals: false`).

**Spec:** [`docs/superpowers/specs/2026-06-19-backend-b2.2-sync-engine-design.md`](../specs/2026-06-19-backend-b2.2-sync-engine-design.md)

**Scope:** Three stores only — `srs_state`, `stats_daily`, `settings`. `decks`/`profiles` are deferred (no local data today; verified). Sync-status UI consumes B2.1's `AccountChip` (reserved a dot) and `AccountSection`.

## Ground truth (verified against the code — do not re-derive)

- **SRS local shape** (`src/lib/srs.js`): `state.srs = { '<deckId>:<cardId>': { box:1..5, lastReviewed:<ms>, nextDue:<ms>, reps:<int> } }`. `lastReviewed`/`nextDue` are **ms epoch numbers**.
- **SRS table** `srs_state`: `(user_id, pack_id, srs_key, box smallint, last_reviewed timestamptz, next_due timestamptz, reps int, updated_at)`. `srs_key` = the `'<deckId>:<cardId>'` key verbatim. **Adapter converts ms ↔ ISO string.** `pack_id` is always `'de'` for now.
- **Daily local shape** (`src/lib/stats.js`): `state.daily = { '<YYYY-MM-DD>': { total, byTab:{chat,alphabet,vocab,translate}, byLevel:{a1,a2,b1:{correct,almost,wrong}} } }`. All leaf values are non-negative integer counters. `emptyDayAggregate()` returns the zero shape.
- **Daily table** `stats_daily`: `(user_id, pack_id, day date, counters jsonb, updated_at)`. `counters` holds the whole `{ total, byTab, byLevel }` object. `day` is the `'YYYY-MM-DD'` string.
- **Settings local sources:** `state.gamification = { goal, soundOn, achievements, lastGoalMet }` + `state.learnedWords = { '<word>': bool }` (both inside the `deutsch-app-state-v1` blob) **plus** `level` stored in the **separate** `localStorage['deutsch-level']` key.
- **Settings table** `settings`: `(user_id, data jsonb, updated_at)` — single row per user.
- **Storage I/O** (`src/lib/storage.js`): `loadState()` → the blob object or `null`; `saveState(obj)` → writes it. The only blob writers are `src/lib/srs.js`, `src/lib/stats.js`, `src/App.jsx`, `src/components/StatsTab.jsx`.
- **Auth** (`src/lib/auth.js`): `useAuth()` → `{ session, user, status }`; `isAuthConfigured()`. Add a `getSupabase()` export in Task 7 (the engine needs the raw client; today `getClient()` is private).

```js
// src/lib/sync/merge.js
// Pure, I/O-free record merge for the sync engine. Each function takes two
// plain objects (local, remote) and returns the merged result. No localStorage,
// no network — fully unit-testable.

// SRS: union of cards; per card, the one with the more recent lastReviewed wins.
// A real timestamp beats null/undefined; an exact tie resolves to remote (server).
export function mergeSrs(local, remote) {
  const out = { ...remote };
  for (const [key, l] of Object.entries(local)) {
    const r = remote[key];
    if (!r) {
      out[key] = l;
      continue;
    }
    const lt = l.lastReviewed ?? -Infinity;
    const rt = r.lastReviewed ?? -Infinity;
    out[key] = lt > rt ? l : r; // strict > → ties keep remote
  }
  return out;
}
```

```js
// Deep zero-filled merge over the daily counter shape. We walk the union of
// keys so a missing side counts as 0 and the shape is preserved.
function combine(a, b, op) {
  if (typeof a === 'number' || typeof b === 'number') {
    return op(a ?? 0, b ?? 0);
  }
  const out = {};
  const keys = new Set([...Object.keys(a ?? {}), ...Object.keys(b ?? {})]);
  for (const k of keys) out[k] = combine(a?.[k], b?.[k], op);
  return out;
}

export function addCounters(a, b) {
  return combine(a, b, (x, y) => x + y);
}
export function subCounters(a, b) {
  return combine(a, b, (x, y) => x - y);
}

// Delta-sync for one day's counters. Push the change since last sync so a
// repeated sync is a no-op and guest data (lastSynced absent → delta = whole
// local value) folds in exactly once.
export function mergeDailyAdditive({ local, server, lastSynced }) {
  const delta = subCounters(local, lastSynced); // lastSynced undefined → delta = local
  return {
    server: addCounters(server, delta),
    lastSynced: local, // advance the baseline to what we just pushed
  };
}
```

```js
// src/lib/sync/syncMeta.js
// Separate localStorage key holding the delta-sync baseline + last-synced time.
// Additive — never reads or writes the main deutsch-app-state-v1 blob.
export const SYNC_META_KEY = 'deutsch-app-sync-meta-v1';

export function loadSyncMeta() {
  try {
    const raw = localStorage.getItem(SYNC_META_KEY);
    if (!raw) return { lastSyncedCounters: {}, lastSyncedAt: null };
    return JSON.parse(raw);
  } catch {
    return { lastSyncedCounters: {}, lastSyncedAt: null };
  }
}

export function saveSyncMeta(meta) {
  try {
    localStorage.setItem(SYNC_META_KEY, JSON.stringify(meta));
  } catch {
    // ignore — meta is reconstructable from a fresh pull
  }
}
```

```js
// src/lib/sync/adapters.js
// Map the local blob slices ↔ Supabase row shapes. pack_id is always 'de' for
// now; the engine adds user_id. These are pure transforms — no I/O.

const toIso = (ms) => (ms == null ? null : new Date(ms).toISOString());
const toMs = (iso) => (iso == null ? null : new Date(iso).getTime());

export function srsToRows(srs) {
  return Object.entries(srs).map(([srs_key, c]) => ({
    srs_key,
    box: c.box,
    last_reviewed: toIso(c.lastReviewed),
    next_due: toIso(c.nextDue),
    reps: c.reps,
  }));
}
export function srsFromRows(rows) {
  const out = {};
  for (const r of rows) {
    out[r.srs_key] = { box: r.box, lastReviewed: toMs(r.last_reviewed), nextDue: toMs(r.next_due), reps: r.reps };
  }
  return out;
}

export function dailyToRows(daily) {
  return Object.entries(daily).map(([day, counters]) => ({ day, counters }));
}
export function dailyFromRows(rows) {
  const out = {};
  for (const r of rows) out[r.day] = r.counters;
  return out;
}

// Settings is one row. `level` lives in a separate localStorage key, so the
// engine passes it in / reads it out.
export function settingsToRow(local, level) {
  return {
    data: {
      goal: local.gamification?.goal,
      soundOn: local.gamification?.soundOn,
      achievements: local.gamification?.achievements,
      lastGoalMet: local.gamification?.lastGoalMet,
      learnedWords: local.learnedWords,
      level,
      settingsUpdatedAt: local.settingsUpdatedAt,
    },
  };
}
export function settingsFromRow(row) {
  const d = row.data ?? {};
  return {
    gamification: { goal: d.goal, soundOn: d.soundOn, achievements: d.achievements, lastGoalMet: d.lastGoalMet },
    learnedWords: d.learnedWords ?? {},
    level: d.level,
    settingsUpdatedAt: d.settingsUpdatedAt,
  };
}
```

```js
// src/lib/sync.js
// Sync orchestrator. No-op unless VITE_SYNC_ENABLED and a session exist. Reads
// the client from auth.js; localStorage stays the offline source of truth.
import { loadState, saveState } from './storage.js';
import { getSupabase } from './auth.js';
import { loadSyncMeta, saveSyncMeta } from './sync/syncMeta.js';
import { srsToRows, srsFromRows, dailyToRows, dailyFromRows, settingsToRow, settingsFromRow } from './sync/adapters.js';
import { mergeSrs, mergeSettings, mergeDailyAdditive } from './sync/merge.js';

export const SYNC_ENABLED = import.meta.env.VITE_SYNC_ENABLED === 'true';

let testClient = null;
export function __setClientForTest(c) { testClient = c; }
function client() { return testClient ?? getSupabase(); }

const PACK = 'de';
const withUser = (rows, userId) => rows.map((r) => ({ ...r, user_id: userId, pack_id: PACK }));

export async function pushAll(userId) {
  const c = client();
  if (!c) return;
  const s = loadState() ?? {};
  const level = localStorage.getItem('deutsch-level') ?? undefined;

  if (s.srs && Object.keys(s.srs).length) {
    await c.from('srs_state').upsert(withUser(srsToRows(s.srs), userId));
  }
  if (s.daily && Object.keys(s.daily).length) {
    await c.from('stats_daily').upsert(withUser(dailyToRows(s.daily), userId));
  }
  await c.from('settings').upsert([{ ...settingsToRow(s, level), user_id: userId }]);
}

export async function pullAndMerge(userId) {
  const c = client();
  if (!c) return;
  const s = loadState() ?? {};
  const meta = loadSyncMeta();
  const level = localStorage.getItem('deutsch-level') ?? undefined;

  // SRS — LWW union.
  const srsRemote = srsFromRows((await c.from('srs_state').select()).data ?? []);
  const srsMerged = mergeSrs(s.srs ?? {}, srsRemote);

  // Settings — whole-object LWW.
  const setRemote = settingsFromRow(((await c.from('settings').select()).data ?? [])[0] ?? { data: {} });
  const setMerged = mergeSettings(
    { gamification: s.gamification, learnedWords: s.learnedWords, level, settingsUpdatedAt: s.settingsUpdatedAt },
    setRemote.settingsUpdatedAt == null ? null : setRemote,
  );

  // Daily — additive delta sync, per day.
  const dailyRemote = dailyFromRows((await c.from('stats_daily').select()).data ?? []);
  const local = s.daily ?? {};
  const nextLastSynced = { ...meta.lastSyncedCounters };
  const serverWrites = {};
  for (const day of new Set([...Object.keys(local), ...Object.keys(dailyRemote)])) {
    const res = mergeDailyAdditive({ local: local[day], server: dailyRemote[day], lastSynced: meta.lastSyncedCounters[day] });
    serverWrites[day] = res.server;
    nextLastSynced[day] = res.lastSynced ?? local[day];
  }
  await c.from('stats_daily').upsert(withUser(dailyToRows(serverWrites), userId));

  // Adopt merged settings/srs/daily locally; advance the sync-meta baseline.
  saveState({
    ...s,
    srs: srsMerged,
    daily: serverWrites,
    gamification: setMerged.gamification ?? s.gamification,
    learnedWords: setMerged.learnedWords ?? s.learnedWords,
    settingsUpdatedAt: setMerged.settingsUpdatedAt ?? s.settingsUpdatedAt,
  });
  if (setMerged.level) localStorage.setItem('deutsch-level', setMerged.level);
  saveSyncMeta({ lastSyncedCounters: nextLastSynced, lastSyncedAt: Date.now() });

  // Push the reconciled SRS/settings back up.
  await c.from('srs_state').upsert(withUser(srsToRows(srsMerged), userId));
  await c.from('settings').upsert([{ ...settingsToRow({ gamification: setMerged.gamification, learnedWords: setMerged.learnedWords, settingsUpdatedAt: setMerged.settingsUpdatedAt }, setMerged.level), user_id: userId }]);
}
```
