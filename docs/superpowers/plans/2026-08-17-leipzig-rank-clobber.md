# Leipzig Rank Clobber Fix — Implementation Plan

**Goal:** Stop the lexicon import silently losing 327 common nouns — including
`Zeit`, `Mann`, `Frau`, `Arbeit`, `Kind` and `Sonntag` — because a later
duplicate key overwrites a better frequency rank.

**Architecture:** the rank-map construction moves out of `index.js`'s private
`readRankMap` into an exported, tested `buildRankMap` in `rankLeipzig.js`, where
the rest of the Leipzig concern already lives. First occurrence wins.

## The bug

`scripts/import-lexicon/index.js:52`

```js
if (word) map.set(word.toLowerCase(), ++rank);
```

Leipzig's `freq.tsv` is **case-sensitive** and carries OCR/typo noise. The real
`Zeit` (count 1109) is at line 152; a junk `zeit` (count 1) is at line 174097.
Both lowercase to `zeit`, `map.set` overwrites unconditionally, and the junk
entry wins because it comes last. `topByRank(…, 5000)` then drops the word.

Measured against the real `freq.tsv`:

| | |
|---|---|
| distinct lowercase keys | 169,200 |
| keys with a later duplicate | 6,465 |
| ranked into top 5000 but clobbered out | **1,561** |
| of those, capitalised nouns | **327** |

Two distinct effects: words are **dropped** entirely, and words that survive
ship with a **corrupted rank** (`die Frage` true rank 379, shipped as 9893).

## Why the suite never caught it

`readRankMap` is private to `index.js` — never exported, never tested.
`rankLeipzig.test.js` hand-builds `new Map([['brot', 142], ['gehen', 12]])`, so
its fixture starts from a map that is already built and contains no
duplicate-case pair. The fixture cannot express the failure.

## Global Constraints

- **Tests use `globals: false`** — import from `'vitest'` in every test file.
- **Never bypass `.husky/pre-commit`**. `--no-verify` is forbidden.
- Rank stays **position in the file**, so ranks of unaffected words do not move.
- `buildRankMap` must accept an async iterable so `index.js` keeps streaming
  rather than buffering `freq.tsv` into memory.
- Open a PR against `main`; never push to `main`.

## File Structure

| file | change |
|---|---|
| `scripts/import-lexicon/rankLeipzig.js` | new exported `buildRankMap` |
| `scripts/import-lexicon/rankLeipzig.test.js` | duplicate-case fixture |
| `scripts/import-lexicon/index.js` | `readRankMap` delegates to it |
| `public/lexicon/de/*` | regenerated by `npm run import:lexicon` |

## Out of scope

- The **newswire skew** in the Leipzig corpus is real and separate: `Prozent`
  #100, `Polizei` #120 are genuine ranks from a press corpus. This fix does not
  make `freqRank` a learner-usefulness signal, and nothing should surface the
  rank to learners on the strength of it.
- Homograph rank bleed (`das Aber` inheriting the conjunction's rank).
