## Why a certification?

I'm pursuing the [**GitHub Foundations**](https://learn.microsoft.com/en-us/credentials/certifications/github-foundations/) certification to formally validate fluency with Git and the GitHub platform. These hands-on practices are the practical backbone of that preparation — each one reinforces a concept the exam assesses, and several (supply-chain security, AI-powered Actions, agent orchestration) go beyond the syllabus into modern tooling.
